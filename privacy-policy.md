# Politique de confidentialité – HideMyContact

**Dernière mise à jour : [02/04/2026]**

## 1. Introduction

HideMyContact est une extension Chrome qui masque les coordonnées de contact affichées sur planity.com. Cette politique de confidentialité décrit comment l’extension traite les données des utilisateurs.

-----

## 2. Collecte des données

HideMyContact **ne collecte aucune donnée personnelle**. L’extension ne recueille pas, ne lit pas et ne transmet pas d’informations permettant d’identifier un utilisateur (nom, adresse, email, identifiants, etc.).

L’extension agit exclusivement en local, dans le navigateur de l’utilisateur, en modifiant l’affichage visuel des pages web visitées sur planity.com.

-----

## 3. Traitement des données

Aucune donnée utilisateur n’est traitée par l’extension. Les opérations effectuées (masquage de contenu HTML) sont réalisées entièrement côté client, sans analyse ni interprétation des données personnelles présentes sur les pages.

-----

## 4. Stockage des données

HideMyContact ne stocke aucune donnée utilisateur, ni localement (localStorage, cookies, IndexedDB), ni à distance (aucun serveur backend). L’extension ne conserve aucune information entre les sessions de navigation.

-----

## 5. Partage des données

Aucune donnée n’est partagée avec des tiers, des annonceurs ou des services analytiques. L’extension ne communique avec aucun serveur externe.

-----

## 6. Permissions utilisées

L’extension utilise les permissions Chrome suivantes :

|Permission                      |Raison                                                            |
|--------------------------------|------------------------------------------------------------------|
|`activeTab`                     |Accéder à l’onglet actif pour modifier l’affichage sur planity.com|
|`scripting`                     |Injecter le script de masquage dans la page                       |
|`host_permissions` (planity.com)|Limiter l’action de l’extension au seul domaine concerné          |

Ces permissions sont utilisées uniquement dans le but fonctionnel décrit ci-dessus.

-----

## 7. Données de rapport (fonctionnalité optionnelle)

Si la fonctionnalité de rapport via EmailJS est activée, l’utilisateur peut envoyer volontairement un signalement. Dans ce cas :

- **Les données transmises** sont uniquement celles saisies explicitement par l’utilisateur dans le formulaire de rapport.
- **Aucune donnée n’est collectée automatiquement** à l’occasion de cet envoi.
- Ces données transitent via le service EmailJS et sont soumises à [la politique de confidentialité d’EmailJS](https://www.emailjs.com/legal/privacy-policy/).

-----
